# What is vcp and how will it work

vcp is a coding agent that incorporates elements of munarium server for memory, intelligently combines multiple models via OpenRouter, and presents a more transparent log of prompts, data, and details that other coding agents do not.

vcp will derive from known best features of claude code, codex, gemini cli, muse code, and others from publicly available documents. It will not borrow any code directly.

vcp will have a cli and a VS Code extension UI and an api similar to other tools, especially claude code, codex, and muse code cli commands with its own flare for intelligently building strategies for mult-model usage based on known strenghts of models hosted by OpenRouter and cost goals: low, med, high.
