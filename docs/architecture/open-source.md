# Full open-source harnesses (code inspectable, forkable)

- **OpenAI Codex** (Apache-2.0) — the Rust engine, app-server protocol, sandboxes, and SDKs are all in `github.com/openai/codex`. Models are OpenAI-only, but the harness is open.
- **Gemini CLI** (Apache-2.0) — still public at `github.com/google-gemini/gemini-cli`, though since June 18, 2026 it only serves enterprise Gemini Code Assist licenses and paid API keys.
- **OpenCode** (MIT) — the most-starred harness on GitHub; client/server design, bring-your-own-model across 75+ providers including local models.
- **Cline** (Apache-2.0) — VS Code-native with Plan/Act modes, full BYOM, SDK and CLI.
- **Aider** (Apache-2.0, Python) — git-native pair programmer with a tree-sitter repo map.
- **OpenHands** (MIT) — event-sourced agent runtime with Docker sandboxing, CLI and web entry points.
- **Pi** (MIT) — minimal TypeScript harness with a sub-1,000-token system prompt and lazy skills.
- **Goose** (Apache-2.0, now under the Linux Foundation), **Continue**, **Roo Code**, **Kilo Code**, **Qwen Code**, **Kimi CLI**, **CodeWhale** — all open source and model-flexible.
- **Claw Code** (MIT) — a community clean-room reimplementation of Claude Code's architecture.
