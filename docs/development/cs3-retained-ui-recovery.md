## Bounded import preparation

When the originals are available, run:

```powershell
node scripts/evals/cs3-retained-ui-import.cjs prepare <packet-directory> <mapping-json> <new-private-directory>
```

The packet directory must contain exactly `index.json` and the six indexed UI
packet files. The mapping is supplied explicitly; its embedded historical path is
never followed. The production command fixes the documented historical index and
mapping hashes, validates each packet digest and salted label mapping, and checks
source files against the frozen v5 inputs. Each variant must contain the exact
allowed final-file inventory. Unknown paths, case collisions, symlinks/junctions,
extra packet files and changed or missing originals fail before staging.

Staging is outside repositories, synchronization roots, original packet and
mapping directories. A fresh Windows destination grants access to the current
owner and SYSTEM; POSIX destinations use owner-only permissions. The importer
copies authenticated packet source strings and overlays the authenticated final
file strings for all eighteen variants, preserving historical completion/check
states. It records per-file hashes and whether bytes came from an original source
or a final-file projection. It then re-authenticates the originals. Nothing is
executed, and no provider is contacted.

`source-manifest.json` uses schema `cs3-retained-ui-import/1`, with `status: prepared`
and `browser_regrade: not_run`. Each run identifies its case, arm, historical label,
completion/check state, relative workspace and bounded file inventory. The manifest
explicitly identifies this representation as the historical reader's redacted
projection, not recovered unredacted workspace bytes. Import success cannot close
browser regrading or erase the historical failed near-miss outcome.

Six contract tests pass, including authenticating a synthetic eighteen-variant
bundle, changed hashes, extra inventory, unsafe/missing final paths, changed source
bytes, duplicate labels, junction rejection and private staging with unchanged
originals. These synthetic tests do not claim recovery of the missing historical
bundle. Production commitment enforcement and explicit failure for missing originals
are tested separately.
