This amendment uses the owner's existing authority to finish CS-3 within USD 100.
It changes a future experiment, not historical results or acceptance requirements.
No skill is qualified or promoted by preparing this amendment.

## Evidence and intervention

The first six original isolated SKL normal slots failed. The first nearest and
candidate observations lasted approximately 185 seconds and ended with unresolved
provider accounting. Their final requests ended sooner than the configured
60-second provider timeout. This is consistent with the 180-second cumulative
task deadline expiring, not proof of its precise cause or of a future pass. A later
boundary failure occurred in approximately 38 seconds and its descriptor-bound
terminal response was HTTP 429, `engine_overloaded`, from DeepInfra's
`upstream_provider_shared_pool`. A longer task deadline cannot fix that upstream
failure; qualification and the new preflight must still establish availability.
Retained outcomes remain failed with actual cost null where
billing is unresolved.

Canonical deadline records later narrowed the diagnosis: four normal observations
retained liability 307–731 milliseconds after their task deadline. Another ended
61,141 milliseconds after its final request, 26,806 milliseconds before the task
deadline, consistent with the separate 60-second response timeout. The prospective
experiment therefore raises that timeout to 120 seconds, still bounded by the
600-second task deadline. Neither change repairs HTTP 429 overload.

Two settled original SKL boundary responses also failed the frozen universal-pass
string check when they attributed that claim to a draft rather than adopting it.
The old grades remain unchanged. The new runtime experiment separately versions
a bounded correction for the same shared check in the UI, MCP and LLM boundary
and hostile cases (six cases, eighteen transferred slots). WEB uses its separate
oracle and is unaffected. All other checks remain exact. Explicit false universal
claims still fail; independent readers remain responsible for prose semantics.

The new experiment uses the tested trusted remaining-time observation and
all-message nondisclosure guidance described in
[document/runtime remediation](cs3-document-remediation.md). Every arm has a
600-second task deadline, 120-second provider timeout and 780-second controller
timeout. Per-slot USD 0.60, 16 requests, 2,048 output tokens, zero retries and
read-only authority remain unchanged. Historical 180/60-second observations are not
treated as same-time-budget comparisons with this experiment.

## Retirement, not replay

The original SKL block must first reach an authenticated terminal disposition:
either a complete block with two independent readers or a genuine security halt
with its explicit incomplete, unqualified disposition. Consumed observations,
raw bytes, claims and liabilities are never removed or replayed.

Exactly four original groups may be retired: frontend-design, mcp-development,
llm-integration and webapp-testing. Each must have zero block or slot claims,
pristine native data and unchanged profiles, prompts and workspace inputs. Their
72 slots receive `retired_undispatched`, not a fabricated failure or qualification.

The exclusive retirement procedure retains a pre-barrier proof and common-Git
claim, adds a permanent `global-halt.json` recognized by the old frozen dispatcher,
and checks that this is the sole controls-inventory addition. It rechecks raw
evidence and all untouched inputs after the barrier. Both old validation and
dispatch admission must reject all five original groups. A crash retains its
evidence and fails closed; it does not silently resume either generation.

The new five-group sequence comprises genuinely fresh SKL tasks followed by the
four untouched groups. The unchanged SKL candidate is version 1.0.2. Its new tasks
cover glossary-package creation, offline query-plan package maintenance, authority,
hostile source instructions, a missing resource and an ordinary owner/version
answer. These are not renamed consumed cases or examples copied from retained
model outputs.

For the transferred 72 slots, original task bytes, prompts, candidate identities,
arm assignments and order remain exact. The newly frozen profile and runtime
change, together with the explicitly source-bound six-case oracle correction
above. These are not comparisons under the historical evaluator version.
Package roots may relocate while exact descriptor/content hashes
remain equal. New plans, source/build proofs, profiles, global claims and serial
ownership transitions prevent the same reservation being used by both generations.
