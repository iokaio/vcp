# ADR-068 — Skills follow-on before other execution hosts

Date: September 24, 2026.
Status: accepted by explicit owner direction.
Owning items: P10-04 deferral; CS-0 scope and qualification design.

## Decision and authority

The owner excluded Linux and macOS for now, then instructed: “Rewrite the plan
accordingly and then begin CS-0.” This accepts the proposed sequencing revision:
defer P10-04 and begin the skills follow-on without waiting for other execution
environments. WSL, SSH and devcontainers are not selected as substitute work.

The [skills implementation plan](../plan/24-skills-follow-on.md) now owns CS-0
through CS-6 as separate follow-on work items. Deliver the six developer-workflow
skills first, then bounded PDF and spreadsheet workflows. CS-0 defines all eight
candidates and their qualification design; this instruction does not authorize
optional CS-7 packs or proceeding into CS-1 during the present scoped task.

This supersedes the whole-P10 sequencing gate in
[the skills research](../research/claudeskills.md#post-plan-roadmap), not P10-04's
acceptance contract. The original architecture ledger remains 67 of 68 complete.
P10-04 stays planned, explicitly deferred; its P8-05 dependency remains unchanged.
The CS ledger is separate and does not alter the original 68-item inventory.

## Preserved boundaries

Native Windows remains the execution and qualification target. The
[host capability baseline](../development/p10-host-capabilities.md) records why
WSL discovery or a generic POSIX adapter cannot substantiate another supported
host. No new environment is advertised and no dispatch gate is relaxed.

Retain P8's [owner-directed closure and qualification gaps](042-owner-directed-p8-closure.md).
M10 statistical observers, other deferred Markov experiments and prompt-audit
proposals remain separate follow-ups. They are neither implemented nor made
prerequisites by this decision. Historical failures, unknown charges and held
liabilities retain their identities.

Skill guidance does not grant process, network, credential or publishing authority.
Paid evaluations need their own authorized budget; this plan does not reuse an
old campaign reservation or authorize a new provider charge. Browser, converter
and recalculation support requires actual Windows qualification before executable
claims. No new third-party dependency is selected by CS-0.

## Consequences

CS-0 can proceed using the existing catalog, discovery, packaging and evaluation
boundaries. Later CS work retains its own evidence gates; documentation completion
does not establish skill usefulness or executable support. P10-04 resumes only
when the owner prioritizes a host and its actual-host qualification is available.
