Workspace view — engine, ownership, trust, roots, extensions

The extension launches only a configured trusted engine executable, negotiates protocol/capabilities, then acquires the permitted controller/observer role. Folder display names are presentation only; identity is (host, workspace_id, root_id). A repository file cannot select the engine executable. Version numbers below are illustrative, not a release compatibility guarantee.
