# P10-03 predeclared observer grading

Declared before implementation qualification, 2026-09-24.

The selected candidate is `exact-verification-repetition/1`, an optional factual
notice after three complete identical failed-verification patterns on unchanged
task, steering and input. It identifies evidence to inspect; it cannot infer a
stall, choose a fix, stop a task or grant authority. M2/M4 did not qualify a
statistical regime observer, so M10 remains deferred.

## Matched comparison

Use identical retained verification traces with the observer disabled and enabled.
Keep root limits, task revisions, check outputs and controller actions identical.
No model is needed for this local observer. Report main and helper requests and
billable amounts separately, plus local elapsed time, bounded evaluations,
duplicate evaluations, proposal bytes and interventions. Zero requests on a local
fixture is not evidence of production task-cost savings.

Primary grading is factual correctness against declared fixture labels, current
revision binding, and absence of duplicated notices. Include constant failures,
alternating failures, incomplete patterns, changing diagnostics, success,
unavailable checks, source edits, steering changes, missing and pruned evidence.
Include repeated environment failures and productive repetition: these are true
repetition facts but do not justify a stall diagnosis or intervention.

The narrow diagnostic benefit is grouped evidence access: one notice gives the
verification references that otherwise require inspecting the individual retained
verification records. Count record inspections, not simulated human seconds.
Do not describe this navigation proxy as measured human productivity. Report the
cost added on negative traces as well as the benefit on positive traces.

Runtime qualification additionally exercises event storms, duplicate delivery,
deadline expiry, exhausted root caps, parent pause, owner loss, restart, and late
completion following user correction. An interrupted attempt requires explicit
resume and fresh relevance checks; status reads cannot trigger work. Since the
selected observer has no model path, prove zero provider admission and preserve
existing shared-ledger liabilities rather than fabricate a slow provider request.

## Acceptance and limits

All safety and factual grades must pass. The optional diagnostic feature is
justified only for showing grouped exact evidence with bounded local overhead.
Default enablement requires separate held-out task outcomes showing completion
quality and total main/helper cost benefits, including false interventions. This
campaign does not supply that evidence; retain the disabled default even when
the diagnostic grades pass. Publish negative or inconclusive results unchanged.
