# CS-3 prospective six-skill comparison

This is a new, unpaid cohort. Historical CS-1/CS-2 candidates, workspaces,
comparisons and terminal claims remain unchanged. `cohort.cjs` defines thirty
new non-WEB cases; the runner imports the six never-paid WEB v1 cases by their
original source and oracle hashes. The WEB near-miss still requires a corrected
`normalize.cjs`; its baseline defect receipt is not a passing solution.

Each candidate receives two substantive normal tasks, boundary, hostile,
missing-prerequisite and near-miss cases, with no-skill, nearest-skill and
candidate arms. All arms return exact file bytes through the same report-only
VCP boundary. The host materializes those bytes for independent contained
execution. Declared `CONTENT_SHA256` descriptor values are sealed identically
for every skill-authoring arm; the original returned JSON remains retained.

The private grader lives outside model workspaces in
`scripts/evals/cs3-comparison-oracle.cjs`. MCP, LLM and the WEB unit repair run
inside the existing zero-capability Node AppContainer. UI artifacts require a
native browser adapter that binds every mandatory action to the exact returned
resource bytes. Preparation fails closed while that adapter's
`validateUiArtifact` entry point or any prerequisite receipt is absent. A
receipt-shaped JSON document cannot replace actual native browser validation.

`cs3-comparison-gates.cjs` validates raw prerequisite schemas rather than generic
success flags. The boundary and Node controls bind current verifier sources and
every mandatory positive/negative observation. The WEB gate reference includes
`path`, `sha256`, `native: {path, sha256}` and `build: {path, sha256}`; admission
recomputes native grades, checks the current compiled source closure and joins
all six case projections to the exact aggregate rows. `web-project` accepts a
JSON file containing that reference and a new private destination outside the
repository, and emits those six authenticated projections without model calls.
All raw evidence is revalidated before paid admission. Historical UI has no
completed regrade validator yet: an importer manifest or prospective UI receipt
cannot satisfy that separate gate.

`cs3-comparison.cjs` reserves at most USD 0.60 / sixteen requests per slot,
USD 64.80 / 1,728 requests for all 108 slots. Native request reservations and
settlements remain authoritative. No retry, replay, paid grader or paid reader
is admitted. A consumed slot remains consumed after a failure or interruption.

`cs3-comparison-review.cjs` prepares two opaque independently shuffled packets
only after required executable checks exist. Mapping hashes and distinct
reviewer identities are retained. Qualification requires every candidate hard
gate and both readers finding benefit over both baselines on the same normal
task. The next skill block requires a fully revalidated terminal disposition;
an integrity, authority, secret-disclosure or unknown-charge failure stops the
whole envelope.

No campaign has been prepared or dispatched from this tree. The prospective UI
native adapter is exported after its current-source controls qualified. Retained
historical UI artifact recovery/regrade remains a separate unmet prerequisite;
the new controls do not replace those missing outputs.
