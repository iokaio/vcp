# API change review

Use this package to review a proposed API contract change and its local evidence.
Read [the compatibility review](references/compatibility.md) and the transitional
[legacy checklist](references/legacy-checklist.md). Return findings; do not modify
an API or publish a review without separate authority.

Separate proposed behavior from delivered behavior. Cite implementation evidence
for delivered claims and report validation as pass, fail, or not_run. Missing
evidence stays unavailable.
