# CS-1 authoring requalification fixtures

This frozen v4 cohort contains two new normal tasks for each prospective CS-1
candidate. The tasks do not reuse a prior task identity, prompt, project, or
expected artifact. Each task is compared under identical inputs and authority
with no skill, the nearest existing skill, and the exact candidate revision.

The project files are model-visible evidence. The private grader files are not
placed in a task workspace or model context. They define structural boundaries,
independent factual observations, reader anchors, and synthetic canaries. Their
observations describe what a blind reviewer must establish; they are not target
prose and do not require phrase matching.

The JavaScript oracle validates frozen input identity, authorized artifact sets,
preservation, reported-byte equality, canary handling, bounds, Markdown links,
and native VCP descriptor hashes. It deliberately does not establish factual
accuracy, usefulness, tool authority, a verifier receipt, or qualification.
Those gates require retained execution evidence, the native checker, and two
independent blind reviews.

All four tasks allow only `vcp_list`, `vcp_read`, `vcp_search`, `vcp_patch`, and
the separately pinned read-only `vcp_verify` checker. They authorize no general
process, network, installation, activation, sending, or publication effects.
The skill tasks additionally require a separately retained feasibility receipt
for the verifier store boundary before any live comparison.
