# Change-note examples
Acceptable excerpt:
Reader: nightly-export maintainers. Delivered: empty exports now retain the header row; implementation evidence: changes/header-row.md. Verification: pass, tests/header-row.txt. Planned: add locale-specific dates; owner: Suri; next checkpoint: design review on August 19.

Unacceptable excerpt:
All exports are better now and everything is tested. Locale-specific dates should be ready soon.

The second excerpt fails to identify the affected behavior, provide evidence for delivery or testing, or assign a planned-change owner and checkpoint. The paths in the first excerpt are examples and are not evidence available in this fixture.
