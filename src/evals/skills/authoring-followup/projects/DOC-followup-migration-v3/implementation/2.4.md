# Exporter 2.4 implementation record
Build: 2.4.0-rc2. The scheduled-job loader rejects cache_dir with CFG21, and rejects a relative cache_root with CFG22 before dispatching the job.

Migration for maintainers of scheduled jobs: locate the directory the old cache_dir actually resolved to under that scheduler's working directory; replace the key with cache_root and its absolute path; run the existing read-only configuration check before restarting that job through the normal release procedure. The check command is exporter check-jobs --config <jobs-file>. This document-writing task authorizes no process execution or restart.

Examples of absolute cache_root values: C:\RelayCache on Windows and /var/cache/relay on Linux. These are examples, not mandatory locations. Credential keys, schedule expressions and output format are unchanged. This release record does not establish production rollout or platform support beyond the tests.
