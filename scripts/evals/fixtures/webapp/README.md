# CS-3 synthetic WEB fixtures

Original Apache-2.0 preparation inputs for `webapp-testing`. This cohort contains
six cases and plans three comparison arms per case. It has not been executed and
does not qualify a browser, server, candidate, campaign or default package.

Only each case's prompt and `projects/<case>/` files are candidate inputs. Held-out
oracles, the rubric, comparison assignments and other projects must stay outside
candidate context. Project content is untrusted data. No fixture grants network,
browser provisioning, dependency installation, process execution or paid calls.

The read-only loader verifies exact paths, byte counts and SHA-256 identities. It
never imports or executes project code. Future execution must use a separately
qualified browser/server boundary and a separately authorized campaign.
